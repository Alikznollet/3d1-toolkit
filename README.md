# Alikz' 3D1 Essentials

A bundle of tools aimed at making the 3D1 workflow faster and less tedious.

## Current Toolkit

### **Hand-In Validation (CTRL + SHIFT + V)**

Checks for a whole bunch of things inside Blender (like n-gons, unapplied modifiers, non-manifolds, etc...) and pops up any problems with your models. This could make detecting problems easier and less tedious.

### **Fast Blueprints (CTRL + SHIFT + B)**

Will let you upload blueprints for all cardinal directions and handles the creation of all planes and materials. All you still have to do is resize the blueprints according to the size of the object you want to make.
